Slide 2 of 5 — Threat Model

The Active Label Inference Attack

Two-Stage Attack Pipeline
Stage 1 — VFL Training

Party A replaces standard SGD with MaliciousSGD. After the chain rule, it amplifies its own parameter gradients element-wise:

ratio = clamp(1 + γ · (g_t / g_{t-1}), min=1.0, max=5.0)
p.grad ← p.grad × ratio

Result: Party A's bottom model learns maximally class-discriminative embeddings. Checkpoint saved to disk.

Stage 2 — Label Inference

Party A loads its saved bottom model, trains a small inference head via MixMatch semi-supervised learning (only 40 labeled samples on CIFAR-10). Recovers training labels of all other parties.

Why It's Hard to Stop
Key Architectural Fact

MaliciousSGD operates on p.grad — the gradient inside Party A's model. The server only sees grad_output — the gradient it sends to Party A. These are different tensors. Gradient norm monitoring therefore cannot detect the attack.

Confirmed Attack Strength (CIFAR-10, 100 epochs)

Key insight: The single-party attack creates a large edge (+10.38pp). The all-parties attack does not — because when both parties amplify symmetrically, no asymmetry exists to exploit. Our defense targets exactly this asymmetry.

Slide 3 of 5 — Core Contribution: Detection Signal

Fisher Criterion as an Attack Detection Signal

The Insight

The Fisher criterion J = Tr(SB) / Tr(SW) measures how class-separable a set of embeddings is. MaliciousSGD causes Party A's Fisher score JA to grow while Party B's JB stays low. The server computes the divergence ΔF = JA − JB each epoch from the embedding tensors it already receives — no access to Party A's model needed.

ΔF = J_A − J_B

Benign training: J_A ≈ J_B → ΔF ≈ 0
Attack active: J_A >> J_B → ΔF >> 0

Slide 4 of 5 — Defense Mechanism

Asymmetric Adaptive Gradient Perturbation

Defense Design

When ΔF exceeds threshold τ (after burn-in), the server scales down the gradient it sends to Party A. Party B's gradient is unchanged — the defense is asymmetric by design.

scale = max(0.0, 1 − α · (ΔF − τ))

grad_output_A ← grad_output_A × scale
grad_output_B unchanged

Novel Mechanistic Discovery

Hypothesis (original): Defense would suppress Fisher divergence — make Party A's embeddings geometrically less separable.

What we found instead: Fisher divergence increases under the defense (0.444 → 0.522 on CIFAR-10). The geometry stays separated. But inference accuracy drops.

Why — Semantic Misalignment

MaliciousSGD amplifies Party A's internal gradients (p.grad) — the defense cannot reach these. So the embedding clusters remain geometrically structured.

But by suppressing the task gradient from the server, the defense removes the semantic calibration that makes clusters correspond to ground-truth labels. MixMatch SSL fails when cluster geometry does not reflect class structure.

Defense breaks: cluster ↔ label correspondence
Defense preserves: geometric cluster structure
Fisher measures: geometry → signal stays high
MixMatch needs: semantics → inference fails

Why this is a stronger contribution: "Defense breaks semantic label alignment" is a more nuanced and novel mechanism than "defense reduces separability" — it reveals a new failure mode of MixMatch-based inference under semantic corruption.

Methodological Note — Corrected

Issue caught and fixed: Early comparisons mixed 30-epoch defended results with 100-epoch undefended results (epoch confound). The attack on CIFAR-10 does not create an inference edge at only 30 epochs — so any defense measurement at 30 epochs tests against a non-working attack.

We identified this, designed the corrected experiment, and it is currently running.
